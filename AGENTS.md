# Agent Instructions

- Do not add Material UI dependencies or imports anywhere in this repository.
- Do not use `androidx.compose.material`, `androidx.compose.material3`, or components from those packages.
- Prefer bare Compose foundation/UI primitives and small local components for buttons, text, inputs, checkboxes, icons, cards, and dialogs.
- Never go beyond making code changes unless the user explicitly asks for more.
- After code changes are done, tell the user the code changes are done and ask the user to handle any follow-up work.
- Never run Gradle tasks.
- Never compile the project.
- Never deploy the project.
- Never interfere with the browser or in-app browser.
